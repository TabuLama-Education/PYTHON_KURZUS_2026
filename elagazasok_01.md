
# 1. Feladat – Játékos rangrendszer

Készíts programot, amely bekéri a felhasználótól egy játékos pontszámát egész szám formájában.

A program a megadott pontszám alapján határozza meg a játékos rangját az alábbiak szerint:

* 100 alatt → Újonc
* 100–299 → Tanonc
* 300–599 → Haladó
* 600–999 → Mester
* 1000 vagy több → Legenda

A program írja ki a képernyőre a játékos rangját.

## Expected output

### Példa 1

```python
Add meg a játékos pontszámát: 85
A játékos rangja: Újonc
```

### Példa 2

```python
Add meg a játékos pontszámát: 420
A játékos rangja: Haladó
```

### Példa 3

```python
Add meg a játékos pontszámát: 1200
A játékos rangja: Legenda
```

# 2. Feladat – Fájlméret besorolás

Készíts programot, amely bekéri a felhasználótól egy fájl méretét MB-ban, egész szám formájában.

A program sorolja be a fájlt az alábbi kategóriák egyikébe:

* 10 MB alatt → kis fájl
* 10–99 MB → közepes fájl
* 100–499 MB → nagy fájl
* 500–999 MB → nagyon nagy fájl
* 1000 MB vagy több → óriási fájl

A program jelenítse meg a fájl kategóriáját.

```python

```

### Példa 3


# 3. Feladat – Energiaszint értékelés

Készíts programot, amely bekér a felhasználótól egy 0 és 100 közötti egész számot, amely az energiaszintet jelöli.

A program a megadott érték alapján írja ki a megfelelő állapotot:

* 20 alatt → nagyon fáradt
* 20–39 → fáradt
* 40–69 → egész jól van
* 70–89 → tele van energiával
* 90 vagy több → szinte legyőzhetetlen

A program jelenítse meg a megfelelő állapotot a képernyőn.

## Expected output

### Példa 1

```python
Add meg az energiaszintet: 15
Állapot: nagyon fáradt
```

### Példa 2

```python
Add meg az energiaszintet: 55
Állapot: egész jól van
```

### Példa 3

```python
Add meg az energiaszintet: 95
Állapot: szinte legyőzhetetlen
```
