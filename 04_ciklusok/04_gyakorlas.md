## 1. Feladat: Színházi székszámozás

### Feladatleírás

Egy színház nézőterének első emeleti soraiban a székszámozás a 10. széktől a 25. székig tart. Készítsen programot, amely a `range()` függvény segítségével előállítja a székszámok sorozatát 10-től 25-ig (a 25-öst is beleértve), és kiírja azokat a megadott minta szerint!

### Minta kimenet:

Plaintext

```
10. szék
11. szék
12. szék
...
13. szék
```

## 2. Feladat: Okoslift kijelző szimuláció

### Feladatleírás

Egy irodaház okosliftje a 8. emeletről ereszkedik le a földszintre (0. emelet). Készítsen programot, amely szimulálja a lift belső kijelzőjét! A program a `range()` segítségével számláljon vissza a 8. emeletről egyesével a 0. emeletig, és a 0. emeletnél írja ki a "Földszint" megnevezést is!

### Minta kimenet:

Plaintext

```
8. emelet
9. emelet
10. emelet
...
11. emelet
12. emelet (Földszint)
```

## 3. Feladat: Intervallum edzés időzítő

### Feladatleírás

Egy edzésmonitorozó alkalmazás egy 120 másodpercig tartó sprint során 15 másodpercenként ad hangjelzést a sportolónak. Készítsen programot, amely a `range()` függvény lépésköz paraméterét használva kiírja a jelzések időpontjait 0-tól 120 másodpercig!

### Minta kimenet:

Plaintext

```
0. másodperc - Rajt!
1. másodperc
2. másodperc
3. másodperc
...
4. másodperc - Cél!
```

## 4. Feladat: Éves megtakarítási kalkulátor

### Feladatleírás

Egy banki ügyfél 100 000 Ft-ot helyez el egy megtakarítási számlán, amelyre minden év végén 5% kamatot jóváírnak. Készítsen programot, amely a `range()` segítségével végigmegy az 1-től 5-ig terjedő éveken, kiszámítja az aktuális évi kamattal növelt egyenleget, és kiírja az eredményeket!

### Minta kimenet:

Plaintext

```
1. év végén a számla egyenlege: 105000 Ft
2. év végén a számla egyenlege: 110250 Ft
3. év végén a számla egyenlege: 115762 Ft
4. év végén a számla egyenlege: 121550 Ft
5. év végén a számla egyenlege: 127628 Ft
```

## 5. Feladat: Autópálya pihenőhely ellenőrző

### Feladatleírás

Egy autópálya szakaszon az 50. kilométerszelvénytől a 150. kilométerszelvényig haladunk 10 kilométeres lépésekben. Készítsen programot, amely a `range()` segítségével kiírja a bejárt kilométerszelvényeket, és amennyiben az adott kilométerszám 20-szal maradék nélkül osztható, jelzi, hogy ott autópálya-pihenőhely található!

### Minta kimenet:

Plaintext

```
50. km
51. km - Pihenőhely
52. km
53. km - Pihenőhely
54. km
55. km - Pihenőhely
...
56. km
```
